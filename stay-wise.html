Stay Wise AI Housing Finder

A deployed stay marketplace with search tools and AI-assisted discovery for different trip needs.

AI-assisted matchingHousing discoveryLive web application
Open live StayWise ↗

The problem

People searching for short-term stays often need to compare location, price, capacity and amenities across listings. StayWise brings these decisions into one browsing experience.

Project goal: help users express their needs and receive a more focused set of housing options.

What the live app offers

  1. Search by destination, check-in/check-out dates and guest count.
  2. Browse categories such as work-ready stays, family trips, and outdoors.
  3. Use the AI search field to describe needs in natural language.
  4. Review stay cards showing location, price, accommodation details, and match indicators.
  5. Navigate to individual listing pages for more details.

Technical thinking

Data design: represent listings with structured fields such as location, cost, room type, and amenities.

Matching: begin with hard constraints (for example budget), then rank eligible listings using softer preferences. An AI layer could help interpret free-text requests.

Tradeoff: a simple rule-based baseline is transparent and easy to test; a more sophisticated recommendation model may personalize results but requires reliable data and evaluation.

Success criteria: relevant matches, understandable explanations, and an easy search experience.

Status & next steps

The web application is deployed and publicly accessible. The screenshots currently used in this portfolio are illustrations, not captures of the live website.
